# wplace-AutoPainter
wplace AutoPainter — это юзерскрипт для браузера, который автоматически переносит любое изображение на полотно wplace.live  с использованием пакетных запросов.

🚀 Быстрый запуск:

Откройте wplace.live и нажмите F12.
Перейдите во вкладку Sources (Источники) 
вкладка Snippets (Фрагменты)
Нажмите New snippet, вставьте код из wplace-autopaint.user.js
Нажмите Ctrl + Enter для запуска. Панель появится в правом верхнем углу

Как рисовать:
После запуска в правом верхнем углу сайта появится темная панель wplace AutoPainter.
Кликните на полотно в том месте, где должен начинаться левый верхний угол вашего рисунка. Координаты в панели загорятся зеленым.
Нажмите «Выберите файл» и загрузите ваше фото (PNG/JPG).
Задайте Width (px) — ширину в пикселях (например, 50–60). Высота рассчитается сама с сохранением пропорций картинки.
Нажмите кнопку Start (0).
Если нужно сделать паузу или накопить новые заряды — жмите Stop, а затем просто нажмите Resume, чтобы продолжить с того же пикселя

Настройки:
Width (px) - 50	Ширина арта в пикселях (50x50 - 2500 пикселей).
Batch size - 80	Количество пикселей установленных за раз.
Delay (ms) -	700	Пауза между запросами.
Start idx	- 0	Номер пикселя, с которого начинать отрисовку, если вы остановились, укажите айди последнего поставленного пикселя, он будет указан в окне.
